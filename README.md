# Copy Path

[简体中文](README.zh-CN.md) · [Download](https://github.com/zcyoung2000/copy-path/releases/latest) · [MIT License](LICENSE)

A small native macOS app that turns **Open With → Copy Path** into a clipboard
action. Use it from Finder or another application to copy the local path of a
file without opening its contents.

Built with Swift, AppKit, and SwiftUI. No third-party dependencies, network
services, login items, or accessibility permission requirements.

## Install and use

1. Download and unzip the application from [Releases](https://github.com/zcyoung2000/copy-path/releases/latest).
2. Move **Copy Path.app** to `/Applications`.
3. Right-click a file in Finder or a compatible application and choose **Open With → Copy Path**.
4. Paste the path wherever you need it.

Multiple files are copied one per line by default. You can also drag files or
folders onto the application icon. Copy Path exits after processing the files.

The release is a universal binary for **Apple Silicon and Intel**, requiring
**macOS 13 or later**. It uses ad-hoc code signing and is not Apple notarized.
macOS may block the downloaded app; after reviewing the source or building it
yourself, use the system's **Privacy & Security → Open Anyway** option if needed.

## Settings

Launch the application directly to open its settings window. The interface is
currently in Simplified Chinese; settings save automatically.

| Setting | Behavior |
| --- | --- |
| 完整路径 — Plain path | Absolute local paths, one per line. Default. |
| 终端引用 — Shell quoting | Single-quoted paths separated by spaces, safe to paste as command arguments. |
| 文件 URL — File URL | Percent-encoded `file://` URLs, one per line. |
| 复制后用指定应用打开 — Forward after copying | Optionally open the same files in an application you select. Off by default. |
| 复制成功时显示短暂提示 — Confirmation | Show a short confirmation without taking focus. On by default. |

With the settings window open, the app stays running. Closing it returns to
automatic exit behavior. File contents are never modified, and the app does
not change any file type's default handler.

## Open With compatibility

Copy Path declares common document, image, audio, video, archive, and source
code types to appear in the system's application candidate lists. It can
receive other local files too.

If it does not appear, choose **Open With → Other…**, select **All Applications**
if necessary, and locate Copy Path. An application started before installation
may need to be quit and reopened to refresh its list. Applications with their
own fixed lists need to support adding an external application.

System candidate discovery is tested for plain text, PDFs, and folders.
WeChat's refreshed menu has not been independently verified. Copy Path 1.0.1
removes the background-agent declaration and recommends `/Applications` to
improve discovery by third-party menus.

The copied path is the local file URL supplied by the source application.
Cloud drives and chat apps may supply a temporary or cached copy; Copy Path
does not preserve that file at a permanent location.

## Build from source

Requires macOS with Xcode or Apple's Command Line Tools.

```sh
git clone https://github.com/zcyoung2000/copy-path.git
cd copy-path
bash scripts/test.sh
bash scripts/build.sh
bash scripts/install.sh
```

The build produces `build/Copy Path.app`, with arm64 and x86_64 slices and a
minimum deployment target of macOS 13. Installation defaults to `/Applications`
and registers the app with macOS. To choose another location:

```sh
bash scripts/install.sh "$HOME/Applications/Copy Path.app"
```

Close a running Copy Path before updating it. The scripts do not require any
signing certificate or API key.

```sh
# Create a release ZIP and SHA-256 checksum.
bash scripts/package.sh

# Optional desktop integration checks; temporarily use and restore the clipboard.
bash scripts/integration-test.sh "$PWD/build/Copy Path.app"
```

GitHub Actions runs formatting tests, builds both architecture slices, verifies
the signature, and saves the packaged app as a workflow artifact. See
[CONTRIBUTING.md](CONTRIBUTING.md) for desktop testing details.
